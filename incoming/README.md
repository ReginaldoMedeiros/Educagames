# 📥 incoming — pasta de entrada de arte

Solte aqui as imagens novas e me avise ("subi") — eu fatio, removo o fundo
e integro no app, depois movo pra pasta final (assets/...).

## Onde colocar cada coisa
- `colorir/`     → desenhos para colorir (line-art P&B). Folha única ou separados. Ideal: 10 por mundo.
- `adesivos/`    → adesivos do Álbum (animais, dinos, espaço, oceano, biblioteca).
- `cosmeticos/`  → folhas de mochilas / sapatos / acessórios / chapéus extras.

## Como subir
1. No GitHub: abra a pasta `incoming/...` → "Add file" → "Upload files" → arraste.
2. Ou git: `git add incoming && git commit -m "arte nova" && git push`

Depois é só dizer "subi".
